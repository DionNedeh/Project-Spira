# Project Spira

An early-stage Voelori public resource about AI infrastructure, electricity, water, local AI, practical action and broader environmental giving.

**Status:** a single static page (`index.html`, `styles.css`, `script.js`) hosted from the GitHub repository; GitHub Pages publication has not been verified. There is no build system, donation collection or analytics.

**Scope:** education only. The page cites published estimates, offers labeled illustrations and qualitative guides, and makes no measured footprint or savings claims. Voelori’s local-AI advocacy and planned future work are owner-provided statements.

**Before publication:** review `research.md`, re-check links, figures and organization details, and update the evidence snapshot date. See `README.md` for structure and maintenance notes.
